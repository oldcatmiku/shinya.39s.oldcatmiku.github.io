学习通挂课方法

  • 2026-09-20
  • 作者 oldcat
  • 489 字

本文最后编辑于 前，其中的内容可能需要更新。

功能

  • 全自动播放，播完自动换 p，不需要人工操作。
  • ai 模型自动答题，自动完成每章后测验。
  • 失焦保护，可以在挂课的时候做其他事情。
    （11.2 更新了 2.5.4 的蓝奏云连接）

以下操作请在电脑上执行。

1.下载软件

github 仓库地址：uxuescript，无法访问则 蓝奏云 下载。
运行 exe 文件，首次打开右下角扫码登录。

2.配置 api

例如 deepseek，在 deepseek 开放平台 创建一个新的 api 密钥，复制输入。
不知道如何配置 api 可以去搜索视频「如何获取 deepseek api 密钥」

  • 如果不配置 api 仅会影响 ai 自动答题功能。

3.开始挂课 & 建议

点进某个课程，弹出如下弹窗就可以直接挂课了。
 

按 Win + D 返回桌面，做任何想干的事情吧！不会影响挂课。

如果想盖下笔记本盖子，通宵运行电脑，那么执行下面的操作：

  1. 按 Win 打开搜索「关闭盖子」，照下图设置。
     
  2. 防止休眠：

不推荐打开强行倍速（Course - Lock PlaySpeed）如果课程设置了观看时长要求，那么开倍速是无效的。
